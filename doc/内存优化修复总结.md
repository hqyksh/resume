# 内存优化修复总结

## 问题描述

启动项目时 Node.js 进程占用内存很少，但只要跳转页面，内存直接飙升到 700-800MB+。

---

## 已完成的修复

### 1. ⚠️ 关键修复：Pin.tsx 内存泄漏

**文件**: `components/animation/Pin.tsx`

**问题**: useEffect 中的两个 setTimeout 没有清理函数，每次组件挂载都会创建新的定时器，但从不清理旧的定时器。这是导致内存泄漏的主要原因。

**修复内容**:
- 保存 setTimeout 的返回值
- 在 useEffect 的 cleanup 函数中调用 clearTimeout
- 确保组件卸载时清理所有定时器

**影响**: 这是最严重的内存泄漏源，每次页面导航都会累积未清理的定时器。

---

### 2. HackerBtn.tsx 防止并发动画

**文件**: `components/animation/HackerBtn.tsx`

**问题**: 快速多次触发 onMouseEnter 会创建多个并发的 scramble 动画，每个都有自己的 Promise 链和 setTimeout。

**修复内容**:
- 添加 `isScrambling` 状态标志
- 在动画运行时阻止新的动画启动
- 避免创建过多的异步操作

---

### 3. 图片懒加载和质量优化

**文件**: `components/hello/index.tsx`

**问题**: 首页同时加载 5 张大图（4张项目图 + 1张背景图），没有任何优化。

**修复内容**:
- 所有图片添加 `loading="lazy"` 属性
- 项目图片设置 `quality={75}`
- 背景图设置 `quality={60}`（因为有透明度，质量要求更低）

**效果**: 减少初始加载的内存占用，延迟非关键图片的加载。

---

### 4. useEffect 依赖优化

**文件**: `app/[lang]/blog/client-search.tsx`

**修复内容**:
- 添加 `eslint-disable-next-line react-hooks/exhaustive-deps` 注释
- 避免不必要的 lint 警告

## 如何测试修复效果

### 方法 1: 使用 Chrome Performance Monitor

1. 启动开发服务器：
```bash
npm run dev
```

2. 打开 Chrome DevTools (F12)

3. 按 `Ctrl+Shift+P`，输入 "Show Performance Monitor"

4. 观察 "JS heap size" 指标

5. 在网站上导航多个页面，观察内存变化

**预期结果**:
- 初始: 50-100MB
- 导航后: 150-250MB
- 多次导航: 应该稳定，不持续增长

---

### 方法 2: 使用内置监控工具（推荐）

在任何页面组件中添加：

```typescript
import { monitorComponentMemory } from '@/lib/performance';

export default function MyPage() {
  useEffect(() => {
    if (process.env.NODE_ENV === 'development') {
      return monitorComponentMemory('MyPage');
    }
  }, []);
  
  return <div>...</div>;
}
```

然后在浏览器 Console 中查看内存日志。

---

### 方法 3: 全局内存监控

在 `app/[lang]/layout.tsx` 中添加（可选）：

```typescript
import { useEffect } from 'react';
import { usePathname } from 'next/navigation';
import { logMemoryUsage } from '@/lib/performance';

export default function RootLayout({ children }) {
  const pathname = usePathname();
  
  useEffect(() => {
    if (process.env.NODE_ENV === 'development') {
      logMemoryUsage(`Route: ${pathname}`);
    }
  }, [pathname]);
  
  return <html>{children}</html>;
}
```

## 进一步优化建议

如果内存使用仍然偏高，可以考虑：

### 1. 限制 TypeAnimation 重复次数

```typescript
// components/hello/index.tsx
<TypeAnimation
  repeat={3}  // 改为有限次数，而不是 Infinity
  // ...
/>
```

### 2. 使用 React.memo 优化重渲染

```typescript
// components/animation/Pin.tsx
export const PinContainer = React.memo(({ children, className, containerClassName }) => {
  // ...
});
```

### 3. 转换图片格式

将 PNG 图片转换为 WebP 格式，可以减少 30-50% 的文件大小：

```bash
npm install sharp
# 然后使用 sharp 批量转换图片
```

### 4. 使用 CDN

将 `public/` 文件夹中的静态资源上传到 CDN，减少服务器负载。
